Week 9 — Scheduling Resources and Costs

This is individual work. Do both parts on your own computer. Your answers are graded, so write each one in full sentences next to the screenshot it refers to.

The project is the conference from Weeks 6 and 7, with two additions: each activity needs one or two of the three event coordinators while it runs, and each has a direct cost. The Week 9 notes explain why that matters. Today you see it two ways: in Smartsheet, as people booked twice on the same days, and in Colab, as the price of solving the problem with a rule of thumb instead of exactly.

Both parts use one file. Download the conference workbook before you start. It has one worksheet:

Column What it holds
Activity, ID The nine activities, A to I, in rows 1 to 9
Duration Workdays, written 2d
Predecessors Row numbers of the immediate predecessors: B’s 1 means “after row 1, A”; G’s 4, 5 means “after D and E”
Start Date, End Date Row 1 starts Mon 2 Nov 2026; Smartsheet fills in every other date
Assigned To Which of Kim, Lee and Ortiz work on the activity
Coordinators How many people the activity needs on each day it runs
Cost Direct cost, used by the notebook

Part 1 · Smartsheet: how the coordinators are used — 45 minutes

1 · Import the workbook

  1. In Smartsheet choose + Create → Import → Microsoft Excel and select the conference workbook.
  2. In the import dialog keep row 1 as column headers and Activity as the primary column. Import.
  3. Check the sheet: nine rows, A in row 1 and I in row 9, nothing below row 9, and Start Date in row 1 reading 11/02/26. If Start Date or End Date came in as text, right-click its header → Edit Column Properties → type Date.

2 · Turn on the project settings

  1. Right-click any column header → Project Settings (or File → Project Settings).
  2. On Dependency Settings, tick Dependencies Enabled. Map the columns: Start Date → Start Date, End Date → End Date, Duration → Duration, Predecessors → Predecessors.
  3. Working days Monday to Friday, holidays none, length of day 8 hours. Click OK.
  4. Every End Date and every later Start Date fills in. If a Predecessors cell came through blank, retype it from the workbook.

Check: row 9 (I) ends Fri 4 Dec.

3 · Show the critical path

  1. Switch to Gantt view (view switcher at the top left of the sheet).
  2. Open the Gantt settings (gear icon on the Gantt toolbar) and turn on Show Critical Path.

Check: A, C, E, G, H and I are highlighted. Take screenshot 1: the Gantt with the critical path.

4 · See how the coordinators are used

Smartsheet’s Resource View is not on every plan; filters work on all of them and show the same thing.

  1. On the toolbar open Filter → New Filter. Condition: Assigned To · contains · Kim. Name it Kim and save it.
  2. Make Lee and Ortiz filters the same way.
  3. Apply each filter in turn. Where two bars overlap on the same dates, that person is working two activities at once.

Record what you see in a table like this one, then take screenshot 2: the Gantt filtered to Kim.

Coordinator Activities that overlap Dates

Ortiz

If your Project Settings dialog does show a Resource Management tab, you may use it instead: change Assigned To to a Contact List column, add a column Allocation % with 100% in every row, select both on that tab, and open the Resource View from the toolbar. Over-booked days show in red.

5 · Resolve one conflict with a resource link

The notes’ parallel method decides that F, which needs two people, waits for E. Smartsheet cannot decide this for you; you type it.

  1. Turn off the filter. In row 6 (F), change Predecessors from 3 to 3, 5. F now starts after E finishes.
  2. F now overlaps G, and Kim is on G. In row 6 change Assigned To to Lee, Ortiz.
  3. Reapply the three filters. No bars should overlap.
  4. In row 6, add a comment: resource link: F waits for E because the coordinators are busy.

Check: the finish moves to Tue 8 Dec. Take screenshot 3: the Gantt with the critical path after the change.

Part 1 questions

  1. What is the finish date and the critical path before you changed anything?
  2. Who is double-booked, on which dates, and by which activities? Why did the critical-path schedule put those activities on the same days?
  3. After the F link, what is the new finish date, which activity joined the critical path, and why?
  4. In one or two sentences: what did Smartsheet do for you, and what did it not do?

Part 2 · Colab: heuristic versus optimum — 40 minutes

1 · Open and run the notebook

  1. Open the Week 9 levelling notebook. It opens in Colab, read-only.
  2. Choose File → Save a copy in Drive. Work in your copy from now on.
  3. Choose Runtime → Run all. The first run takes about a minute. If Colab asks whether to run a notebook not authored by Google, choose Run anyway.
  4. Section 0 downloads the same conference workbook and prints the activity table. Check it against your Smartsheet sheet: nine activities, the same predecessors, the same coordinators.

If Colab is blocked on your network, download the notebook and upload it to Colab with File → Upload notebook from another connection.

2 · Read the results for two coordinators

The notebook starts with LIMIT = 2 in the EDIT cell: Ortiz has left, and Kim and Lee carry everything. Scroll through the output.

Section What to read
1 · CPM The network duration with unlimited people and the critical path; should match Smartsheet’s 25 workdays
2 · Loading chart Coordinators needed each day; red where the early-start plan needs more than two
3 · Parallel method The chapter’s heuristic, with a log of every decision and the finish day
4 · Optimum The best possible schedule, found by trying every order the logic allows
5 · Checks Both schedules respect every predecessor and never use more than two people
6 · Report Both Gantt charts and the summary table with the penalty in dollars

Take screenshot 4: the two Gantt charts in section 6. Take screenshot 5: the summary table below them.

3 · Run it again with three coordinators

  1. In the EDIT cell change LIMIT = 2 to LIMIT = 3.
  2. Choose Runtime → Run all again.
  3. Read the finish days in the summary table. Take screenshot 6.

Part 2 questions

  1. With two coordinators, what finish day does the parallel method give, and what does the optimum give? What is the difference in workdays, and in dollars at the venue’s $1,500 per workday past day 32?
  2. Read the parallel method’s log in section 3 at period 2. Which activity did the rule start, which did it delay, and why did that choice cost days?
  3. With three coordinators, does the notebook’s finish agree with the finish you reached in Smartsheet in Part 1? Workday 27 is Tue 8 Dec.
  4. With two coordinators, which schedule would you give the sponsor, and what would you tell them about day 32?
