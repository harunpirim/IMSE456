This is individual work. You build both forms yourself. The comparison at the end is only worth something if you saw both tools behave.

You are going to build one proposal form, two ways: once by asking a model for it, once by importing a spreadsheet into Smartsheet. Same fields, same example, both times — so that anything that differs is the tool, not the brief.

Part 1 · The AI form — 20 minutes

Open the model and paste this prompt exactly as written. The field list is what keeps the two forms comparable.

Build a modern, single-file HTML project proposal form.

Fields, in this order:
Project Title, Proposal #, Date Submitted, Sponsor, Project Classification,
Business Problem Solved, Reference Link, Strategic Alignment, Major Deliverables,
Impact of Not Doing Project, Risk 1, Risk 2, Risk 3, Success Measures,
Requires Internal Resources?, Resources Available?, Estimated Cost,
Duration (Weeks), Oversight Action.

Rules:
- Project Classification is a single-select: Strategic, Operational, Compliance.
- Requires Internal Resources? and Resources Available? are single-select Yes/No.
- Oversight Action is a single-select: Accept, Return, Pending.
- Estimated Cost is currency. Duration (Weeks) is a number. Date Submitted is a date.
- Business Problem Solved, Strategic Alignment, Major Deliverables,
  Impact of Not Doing Project and Success Measures are multi-line.
- Everything except Reference Link is required.
- Inline CSS, no frameworks, no external files. It must open in a browser on its own.

Pre-fill it with this example: Automated Vehicle Locator (AVL), proposal 11,
sponsor J. Moran, Operational, $10,000,000, 22 weeks.
  1. Save the result as proposal-form-ai.html and open it in your browser.
  2. Try to submit it with a required field empty. Note what happens.
  3. Screenshot the rendered form. You need this later.

If the model returns something that will not open, or drops fields, say so and ask it to fix it. That round trip is worth recording — it is one of the differences you may end up writing about.

Part 2 · The Smartsheet form — 30 minutes

Download project-proposal-form.xlsx. It has two tabs: the column headers, and a Setup Guide tab with the steps and the column types. Follow the Setup Guide — it is the specification for this part.

The short version, which the guide gives in full:

  1. In Smartsheet, File → Import → Microsoft Excel, with My data has column headers checked. Smartsheet imports the first tab only; the Setup Guide tab is for you.
  2. Set each column to the type the guide lists — right-click the column header, Edit Column Properties. The dropdowns and their values are in the guide’s table.
  3. Forms → Create Form. Smartsheet builds one field per column.
  4. Hide Approved By and Oversight Decision Date on the form. Those are filled after review, not by whoever submits.
  5. Mark the required fields, add help text where a field needs it, then Save and get the share link.
  6. Open your own form link and submit the AVL example from the guide’s Example value column. Check the row landed on the sheet.

Screenshot two things: the form as a submitter sees it, and the sheet row your submission created.

Part 3 · Reconcile — 15 minutes

This is the graded part. One page, three questions, specific answers.

  1. Similarities. What did both tools get right without being told twice?
  2. Differences. Where did they diverge — field types, validation, what happens to a submission, what you had to fix by hand? Name at least two differences and say which tool handled it better, and why.
  3. Integration. Pick one PM system you have seen or used — Taiga, Jira, MS Project, a Blackboard workflow, a shared spreadsheet. Which of these two forms could feed it, and what would have to exist for that to work? One paragraph, concrete.

“Smartsheet was easier” is not an answer. “Smartsheet enforced the Accept/Return/Pending choice at the column level, so a bad value cannot reach the sheet; the AI form validated in the browser only, and the data has nowhere to go when you hit submit” is.
