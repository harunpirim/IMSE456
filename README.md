# IMSE 456/656 — Program and Project Management

Course site for IMSE 456/656, Fall 2026, North Dakota State University.
Live at **<https://harunpirim.github.io/IMSE456>**.

Built with [Quarto](https://quarto.org) 1.6.43 and published by GitHub Actions.

## How the weekly release works

Every week page carries a `release:` date in its front matter:

```yaml
---
title: "Week 5 · Schedule I — networks, CPM, float"
week: 5
release: "2026-09-21"
video:
  provider: none      # none | youtube | kaltura | file
  id: ""
---
```

`scripts/gate.py` copies the whole tree to `_build/`, and in that copy replaces the body of
any week, slide deck, or lab whose release date is in the future with a short
"opens on ..." stub. It also regenerates `schedule.qmd` from every week's front matter and
expands the `<!-- VIDEO -->` marker into the right embed. **The source tree is never
modified**, so running it locally is safe.

The Action runs on every push to `main`, once a day at 11:00 UTC, and on demand from the
Actions tab. Write all sixteen weeks whenever you like; each one appears on its own date.

## Working on the site

```bash
pip install -r scripts/requirements.txt

python3 scripts/gate.py                    # gate as of today (America/Chicago)
python3 scripts/gate.py --date 2026-10-06  # preview the site as students see it in Week 7
python3 scripts/gate.py --all              # ungate everything
quarto preview _build                      # then look at it
```

`gate.py` prints which weeks are live and which are gated. Check that output before pushing
a change to any release date.

## Adding a lecture recording

1. Upload to YouTube as **unlisted** (or to Kaltura).
2. In `weeks/week-NN.qmd`, set `provider: youtube` and `id:` to the eleven-character video ID.
   For Kaltura, set `provider: kaltura` and put the full watch URL in `id:`.
3. `git push`. The Action rebuilds within a minute or two.


## What does not belong in this repository

It is public. Keep out of it:

- Solution keys, exam items, and auto-marking shells
- Anything derived from the Larson instructor manual or digital image library — that
  material is licensed to the instructor, not to the public
- Student names, grades, submitted work, or recordings of student voices (FERPA)

Those live in a separate private repository.

## Caveats worth knowing

- **Cron is UTC and DST-blind.** `0 11 * * *` is 06:00 Central until 1 November, then 05:00.
- **GitHub disables scheduled workflows after 60 days without repository activity.** Over a
  long break the daily build will silence itself; re-enable it from the Actions tab, or use
  the manual `workflow_dispatch` trigger.
- **Gating is cosmetic, not access control.** An unreleased week is removed from the built
  site, but its `.qmd` source is readable in this public repo the whole time. That is fine
  for lecture notes and is the reason nothing with an answer in it lives here.
